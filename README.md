# Ryggsäcken

**Allt du behöver för skoluppgifterna.** Ett stöd för elever med tre verktyg:

- ✍️ **Skrivstödet** – från uppgift till färdig text: skrivprocessens steg, referenssystem, granskning och tips för Google Docs och Word.
- 🗓️ **Planeringshjälpen** – dela upp prov och uppgifter i små steg med datum, se "Min vecka" och använd fokustimern.
- 🔎 **Källkollen** – granska en källa steg för steg (äkthet, tid, beroende, tendens) och få en färdig motivering.

## Integritet

Allt körs i elevens webbläsare. Inga uppgifter skickas någonstans, inga kakor för spårning och inga externa skript eller typsnitt. Det eleven skriver sparas bara lokalt (localStorage/sessionStorage).

## Använd på en Google Site

**Länk:** `https://joshuamrumack-collab.github.io/ryggsacken/`

1. Öppna din Google Site i redigeringsläge.
2. Välj **Infoga → Bädda in → Via webbadress** och klistra in länken ovan.
3. Välj **Hela sidan** och dra upp rutan så att den blir hög.

Alternativt: **Infoga → Bädda in → Bädda in kod** och klistra in hela innehållet i `index.html`.
